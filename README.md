# Tic-Tac-Toe

A simple browser-based Tic-Tac-Toe game for two players. Enter player names, take turns on the board, and keep track of scores.

## Play online

[Play Tic-Tac-Toe](https://pranaybhardwaj29.github.io/tic-tac-toe/)

## Run locally

Clone or download this repository, then open `index.html` in a web browser.

## Built with

- HTML
- CSS
- JavaScript
